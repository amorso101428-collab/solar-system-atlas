# HUMAN ARTIFACTS

**A Cartography of Humanity in the Solar System** —— 一张可交互的太阳系人类造物图谱。

打开是一张安静、巨大的宇宙工程图；右键转动视角时，轨道从"正对镜头的平面图谱"
展开成真实的轨道倾角；点击任一天体或航天器，镜头以它为原点推近，左侧是空间场景，
右侧是它的档案。

## v9.1：三处修正

### 1. 时间轴拖动是"瞬移"的真正原因（重要）

`realHeliocentric()` 与 `daysSinceJ2000()` 都用
`new Date(Date.UTC(year, 0, 1))` 换算天数，而 **JS 的 `Date.UTC` 会把年份字段取整**：
传进 2026.35 会被当成 2026。于是时间轴连续拖动时，行星的黄经只在"跨年"那一瞬间
跳一次，中间完全不动 —— 这就是"到一个时间点，瞬移过来"。

现在改成连续年份：`days = (year - 2000) × 365.25`。实测（实时位置模式）：

```text
目标年份 2000 → 平滑年份 2014.6 → 地球世界坐标 (32.81, −23.74)
目标年份 2000.25 → 2004.9 → (21.47, 33.19)
目标年份 2000.5 → 2003.9 → (28.10, 27.95)
目标年份 2000.75 → 2001.9 → (19.96, 34.10)
```

年份与坐标都是连续变化的，行星沿轨道滑行而不是跳点；彗星、自转相位同样受益。

### 2. 详情面板的关闭按钮吸顶

`.archive__top` 改成 `position: sticky`（配合负 margin 抵消面板 30px 内边距
与一层从面板底色渐隐的底衬）。实测：面板滚动 900px 后关闭按钮仍停在原处
（y=126，`sticky: true`），读长文中段也能随时关闭。

### 3. 语录栏不再和品牌标题重叠

语录栏从 `top: 236px` 下移到 **268px**：带返回键时品牌标题占 122–247px，
236 会压住它的最后一行"145 收录对象"。实测语录栏 268–333、标题块 112–237，
`overlap: false`。主页署名行同时改成 `© 2026 ESSELANO · 小红书 · 哔哩哔哩 · 抖音`，
三个平台全部可点击跳转。

## v8.3：音乐播放修复 + 聚焦标识清理

### 1. 音乐"加载成功却没有声音"的根因

之前把音乐接进了 Web Audio（`createMediaElementSource` + `crossOrigin='anonymous'`），
而在线流的 CDN **不返回 CORS 头**——浏览器就会静音，控制台也没有明显报错。
现在音乐**完全不经过 Web Audio**：

```text
HTMLAudioElement 播放（跨域直链 / 自选文件一视同仁）
   ↓
淡入淡出、交叉淡入淡出 = 渐变 el.volume（60ms 步进）
   ↓
音量、进度、切曲都直接作用于元素
```

同时按用户建议加了**自定义音源**：可以给任意一首粘一个能直接播放的地址
（网易云 `music.163.com/song/media/outer/url?id=…` 这类直链、其它平台直链、
自己服务器上的音频都行），设置记在 `localStorage`。
播放源现在是「官方在线流 / 自定义音源」两项。

### 2. 聚焦时那个"巨大的环"

`FocusHalo` 原来除了四个角标，还会把目标自己的**整条轨道**画成一圈椭圆，
聚焦时横跨半个屏幕。现在只留四个角标（+ 进入时 250ms 的展开），
整圈椭圆与沿环跑动的短轨迹都删掉了。

顺带把标注排布理顺：地貌标签统一挂**左侧**，大气/结构数据尺固定在**右临边**，
两者不再互相压字。

## v8：三段式开场 · 真实俯视 · 行星全息分析

按《V8 超详细修改方案》的 Phase 顺序推进，本轮完成 A/B/C/D/E 的主干。

### 1. 开场：未来复古圆形仪器 → 真实位置俯视 → UI 退场 → 俯视转侧视

```text
圆形仪器盘（三层环 21s / 7.4s / 2.1s + 字符解码 + 遥测行）
   ↓ 加载完成，圆盘向外扩张淡出（980ms）
真实位置俯视全景（相机 pitch 81°，行星用当前 epoch 的真实日心黄经）
   ↓ 点击进入 → 落地 UI 退场 0.5s（镜头不动）
俯视 → 侧视连续过渡 2.2s（位置同时从真实黄经滑回示意图排列）
```

- 俯视图与图谱是**同一个场景**：`topShot` 只是把 target 归零、pitch 抬到 81°，
  所以圆盘扩张之后看到的就是真实太阳系，不存在"切页"。
- 背景失焦用 `uDefocus`：星点变大变淡（星野层专用），行星与轨道始终锐利。
- 落地文案上移 13vh，避开画面中心的日面。

### 2. 时间轴阻尼

根因是 `setTimelineYear` 里的 `Math.round(year)` —— 目标年份被量化成整年，
滑杆再细也只在整年之间跳。现在保留浮点，追赶交给 `utils/clock.ts`
（指数衰减，时间常数约 0.2s），拖动是"星历在滑动"而不是逐格跳。

### 3. 尺度与粒子

- **行星间距**（§13）：外太阳系按"相邻盘半径 + 6 单位净空"重排 ——
  木星 88 / 土星 122 / 天王星 152 / 海王星 175 / 冥王星 194。
  聚焦木星时背景不再塞满土星的轨道线。
- **小行星带不侵入行星轨道**（§14）：带体不再由 AU 曲线决定，而是
  `[火星盘外缘 + 2, 木星盘内缘 − 2]`，行星怎么调间距它都自动跟随。
- **越近越丰富**（§15）：粒子池 16000，每颗带自己的出现阈值 `aReveal`，
  细节等级随视高连续变化；远景 1.35px 薄尘、近景一整条能数清的小行星带。
- **柯伊伯带 / 奥尔特云 = 粒子密度壳**（§17 / §18）：删掉上一版的菲涅尔球壳网格，
  改成 `seededShell(bias = 0.35)` 的**外密内疏**粒子分布（奥尔特云 16000 颗），
  包裹感来自密度本身。缩放下限 380 → 760，整层壳才装得进画面。

### 4. 太阳闪烁

不是亮度问题，是**亚像素几何在闪**：日冕 / 色球 / 日珥在缩到全览时只有
8–9px，逐帧噪声就变成闪烁。现在按太阳的屏幕半径 `detailFade` 把这三层连续淡出，
光晕的缩放也加了上限（不再随视高无限长大）。日珥同时缩小到 0.03–0.075 个太阳半径、
只留 3 处活动区（§22）。

### 5. 人造卫星轨道与 marker 同步

旧版是四个不同阈值（轨道 70 / 小卫星 84 / 卫星点 26 / 标签又是另一套），
所以"轨道出来了点还没出来"，而且到点就跳。现在统一成两个连续函数：
`satelliteVisibility`（主）与 `minorSatelliteVisibility`（更晚出现的小卫星层），
轨道线、卫星点（逐颗 `aAlpha`，按**自己母星系统**的屏幕大小）、标签全部乘同一组值，
再各自做指数阻尼 —— 推近是一次连续浮现。

顺带修掉一个一直存在的隐性 bug：卫星点的顶点着色器用了 `uOpacity` 却没声明，
shader 编译失败，那些圆点其实从未真正渲染过。

### 6. 右键转视角静音

右键拖动全程无声（§21）。真正的噪声来源不是某个音效，而是拖动时指针划过天体
一路触发 hover 音——现在拖动期间 `muteHover(true)`，松手恢复。

## 上一版（v7.2）：LOD、球壳、衔接与进场加载

### 1. 小行星带：越近越丰富（v7.1 做反了一半）

v7.1 只解决了"缩小反而变大"，但把近景可见粒子砍到 32%，于是放大之后
**根本看不出有一片小行星带**。这一版把数量与细节都改成随镜头推进而增长：

```ts
// 每颗粒子带自己的出现阈值 aReveal（0…1），着色器里：
float appear = smoothstep(aReveal - 0.1, aReveal + 0.02, uDetail);
// uDetail：缩到最远 ≈0.05（只剩薄薄一层尘），推到最近 ≈1（全开）
```

配三件事：

- 粒子总量 5200 → **16000**（远景只露出最早的一批，近景才有东西可数）。
- 每颗粒子有自己的尺寸系数（0.72–1.34）与色调偏移，近景因此有层次，
  而不是"一片同样亮度的点"。
- 远景仍然保持 v7.1 的负指数尺寸规律（3.40px → 1.35px），
  加上 L0 淡环带与 Kirkwood 空隙，所以"远看是一条带、近看是一地小行星"。

### 2. 奥尔特云：菲涅尔球壳

点云本身只是散点，拉远时读不出"把太阳系包住"。现在在 175 / 285 两圈半径上
各加一层**菲涅尔球壳**（正对镜头几乎透明、掠射边缘最亮），外壳比内壳更淡，
于是有前后层次而不是一团雾。缩放下限也从 380 放宽到 640 —— 旧的限制根本装不下
半径 285 的球壳，"拉到最远"永远看不到它。

### 3. 主页背景 = 图谱本身，进入是一次连续拉远

这是本轮最重要的一处结构性修改。旧版主页画的是**另一套装饰**（一个 sprite 太阳 +
四条装饰弧），进入图谱时只能把它们抹掉、再把真场景换上来——所以看起来像换页。

现在：

```text
开场：相机停在同一构图的 1.82 倍近景（introShot = atlasShot × 0.5，目标点左移 12.5）
      看到的就是真太阳、真轨道、真行星与真星场
进入：1.4s 内从 introShot 连续拉到 atlasShot
      轨道线在地原地变亮（0.42 → 1），小行星带从 0.34 升到 1，
      行星与深空天体从画面边缘自然走进来，标签最后淡入
```

不再有"切换"这个动作，也没有淡到黑。`IntroCosmos` 现在只剩一层贴镜头的尘埃，
它随镜头退掉。

### 4. 进场加载页（未来复古主义 · 极简线条）

`?boot=hold` 可以停在加载页看排版；默认流程是：

```text
加载页（细线外框 + 32 格刻度 + 32 位百分比 + 三个阶段清单）
   ↓ 全部素材拉完（并且至少显示 1.1s，避免"闪一下"）
开场 → 进入图谱
```

- 清单不是手写的：行星 / 卫星贴图从数据里取，音效从 AudioManager 的映射表里取。
- 进度优先按 **Content-Length 字节**推进；文件大小差 20 倍时按个数会假死。
- 关键点：**加载页背后主场景已经在渲染**（v7.2 之前开场是把图谱 `visible={false}`，
  贴图要等到进入的那一刻才上传，这就是"进侧视图卡一下"的原因）。

### 5. 音效：minimal / studio / dreamy

用户反馈上一版"太单调，噔噔咚咚"——那是 `mechanical` 人格（继电器 / 开关）。

## v7.1：审美纠偏 —— 小行星带与音效

这一轮只降"玩具感"，不加任何特效：删掉错误表现，重建视觉与声音的层级。
判断标准只有一句话——**这是展陈级的天文图谱，不是太空游戏 HUD。**

### 1. 小行星带：缩小视图时粒子反而变小

根因是一行公式写反了方向：

```ts
// 旧：视口越高（缩得越远）→ 粒子越大，最大 3.4px
const beltPointSize = THREE.MathUtils.clamp(viewHeight * 0.016, 1.1, 3.4)

// 新：负指数。远景更小、近景略大（§3）
const size = base * Math.pow(viewHeight / 240, -0.18)  // clamp 到 0.8–2.2px
```

实测（`tools/ui-probe.ps1 -Wheel`）：

| 取景 | 可见高度 | 旧 | 新 |
| --- | --- | --- | --- |
| 远景（缩到最远） | 283 | **3.40px** | **1.35px** |
| 默认总览 | 98.5 | 1.58px | 1.58px |
| 近景（聚焦木星一带） | 26 | 1.10px | 2.16px |

配套改了三件事，都是为了"用密度换尺寸"而不是"用尺寸换存在感"：

- **颜色与亮度**：`#b3a894` → `#8f8676`，不透明度 0.30 → 0.17，永远低于标签与行星（§5）。
- **密度换尺寸**：远景把 5200 颗粒子全摊开，推近只剩 32%（约 1660 颗）——
  稀疏才读得出"一颗颗小行星"，而不是一片亮噪声（§7）。
- **L0 带体**：新增一层极淡环带（`RingGeometry` + 程序噪声着色器，0.08 不透明度），
  远景先读成 `火星 ──[ 淡带 ]── 木星`，再读成很多点（§4）。环带里做了
  2.50 / 2.82 / 3.27 AU 三处 **Kirkwood 空隙**——那是轨道共振真的把小行星清空的位置。
- **视觉权重**（§8）：默认 0.15；聚焦小行星带 0.65；聚焦行星 0.10；聚焦卫星 / 航天器 0.05。
  别的天体当主角时，小行星带自己退到背景。柯伊伯带在远景的不透明度也从 0.46 压到 0.22。

### 2. 音效：从"8-bit 提示音"换成机械与电影感

上一版取的是 uisfx 的 `scifi` 人格——官方描述就是 clean holographic ping 加
digital shimmer，配上每一下都响的 0.3–0.6 增益，听感就是游戏按钮。这一版：

- **换人格**：离散交互走 `mechanical`（继电器 / 开关 / 硬件），聚焦与转场走
  `cinematic`（低频冲击 + polished tail）。`arcade` 明确不用，`public/audio/scifi/`
  整个删掉，抓取脚本改成多包（`tools/fetch-ui-sounds.mjs`）。
- **换层级**（§16）：新增 `MASTER 0.65 → UI 0.42 / AMBIENCE 0.18 / MUSIC`，
  cue 增益按 §13 重排：hover ≈ -31dB、click ≈ -22dB、focus 更响且更宽。
- **换结构**（§14）：一个事件可以是一串声音。打开在轨目录 = 轻开 →
  扫描纹理 → 落定音；聚焦 = 低频起音 → 420ms 后的落定音；进入图谱 =
  低频涌起 → 880ms 的落定音（对齐 1.4s 的镜头推进）。
- **换细节**：hover 节流 110ms 且截断到 46ms（§17），时间轴 tick 节流 80ms 且截断到 70ms，
  截断处一律淡出；open / focus / back 加立体声展开，click 保持居中干声（§18）。

19 个 cue 的加载状态由 `?debug=1` + `window.__atlasAudio.cueStatus()` 自检，
实测 `{"total":19,"missing":[]}`。

### 3. 顺手修掉的两处"抢画面"

- **行星标签在极度缩小时叠字**：内行星的屏幕 x 会收敛到太阳附近，同一侧的

- **柯伊伯带在远景被提亮**：旧公式在远景把它推到 0.46 不透明度，半屏都是灰颗粒；
  现在 0.08–0.22（选中时 1.8 倍）。

旧版每颗行星停在自己轨道上的随机位置，再乘上各自的轨道倾角——水星比金星高、
火星比地球低，"一串行星"读起来是一条上下乱跳的折线。

### 2. 卫星同心圆：一圈一圈**等距的正圆**

- `DISK_SQUASH` 从 0.78 改成 1。旧版把盘内轨道压扁成椭圆，半径 8.9 的那一圈
  短轴只剩 6.9，比土星环外缘的 8.5 还小——于是轨道线从环里穿了过去。
- 最内圈 = max(本体半径 × 1.5, 环外缘 × 1.14)：土星环永远落在轨道线**里面**。
- 主要卫星（月球 / 伽利略四卫 / 土卫一·二·六·八 / 天卫五·三·四 / 海卫八·一 / 冥卫一）
  在盘内**等距**排开，其余小卫星按真实轨道顺序插进相邻两圈之间。
- 轨道 LOD 阈值提到 70 / 84 像素：总览只留主要卫星那几圈，
  几十圈人造卫星与小卫星必须真的推近才逐层浮现，否则等距的正圆会糊成一圈亮斑。
- 推近行星时的镜头几乎正对系统盘法线（旧版多转了 15° 以上，正圆又被压成椭圆）。

### 3. 外太阳系重新分配距离

木星 70 → 66、土星 90 → 96，天王星 / 海王星 / 冥王星顺推成 118 / 133 / 144：
相邻两圈的同心圆之间留出净空，木星的最外圈不再切进土星环。行星视觉半径不变。

### 4. 彗星：删掉圆锥，改成平面 UI

3D 里只剩那条高偏心率的真实轨道线；彗星本体是 DOM 里的 `.comet-marker`——
一个核 + 一条**指向"背离太阳"方向**的尾迹线 + 一枚小箭头，
长度随近日点活跃度在 20~40px 之间变化，任何缩放下粗细一致。

### 5. 距离比例继续放宽 + 卫星轨道盘放大

水星 14 / 金星 26 / 地球 38 / 火星 53（**水星→地球 = 水星→金星 × 2**），
木星 79 / 土星 106 / 天王星 130 / 海王星 148 / 冥王星 162；
每个行星的系统盘同步放大（木星 12.2 / 土星 14.5 / 天王星 8.8…），
等距的同心圆排得更松、更好读。

### 6. 轨道 LOD 改成渐变

盘内每一条轨道都有一份**自己的材质副本**，缩放时按自己的节奏淡入淡出（约 0.35 秒），
不再"啪"地整片出现或消失；卫星点标记同样带阻尼。

### 7. 太阳改成色球层观感 + 真正的日珥

- 日面按亮度查一条**橙色斜坡**（深红橙 → 橙 → 活动区黄白），
  而不是旧版"白中带暖"的色温斜坡——旧版在深色图谱里像一颗曝光过度的月亮。
- 暗条用**噪声等值线**取脊线，得到的是细长弯曲的深色丝状结构（旧版是团块黑斑）。
- 日珥：18 颗 × **3 股细丝**（中间那股利最亮），弧面改成**竖直**的
  （法线 × 世界上方向张开的平面）——旧版画在黄道面里，镜头几乎沿黄道面看过去，
  所有环都被压成从边缘射出去的直线，也就是"边上画了两条弧线"。

### 8. 地球 / 火星

- **地球**：云层对比拉满（云顶纯白 + 薄云保留）、海洋压成深海蓝、
  加海面镜面反光、受光区放宽（昼夜线从 -0.05→0.30 改成 -0.12→0.24），
  终于有 Blue Marble 那种明亮的蓝。
- **火星**：删掉程序化白极冠——`mappedSurface` 里那圈 `smoothstep(0.8, 0.97)` 的白，
  就是"上下两片白雾"的来源，它盖在贴图本来就有的极冠上。

### 9. 字体 / 光标 / 误选

- 全站字号上调约 15%、字重提到 500（标签 11.5px，行星名 13.5px，档案正文 13.5px）。
- 文字动效：标签出现 / 消失是 260ms 渐变，导航 hover 从左侧扫出一条下划线。
- **自定义光标**：十字准线 + 圆环，悬停天体 / 航天器时圆环张开并转成暖橙，
  悬停 UI 控件时亮一档，按下时收缩。系统光标在整站被关掉。
- 拖动图谱时不再误选文字（`user-select: none`，输入框除外）。

### 10. 冥王星 / 冥卫一的贴图

- **冥王星以前指向 `planets/moon-2k.jpg`**——就是月球那张图，已换成 New Horizons
  全球彩色拼接图 `planets/pluto-2k.jpg`（Wikimedia Commons，公共领域）。
- **冥卫一以前没有贴图**：`fetch-moon-textures.ps1` 当初跳过它，因为 Commons 上那张
  全球图带印刷标注，于是只剩程序化表面。现在补上 `moons/charon.jpg`
  （NASA/JHUAPL/SwRI，iau1803c 无标注版）。
- 两张都是"有效纬度带画在黑底上"的拼接图，直接贴球会在两极留黑洞。
  `tools/fetch-dwarf-textures.ps1` 会自动找出最长的有效行区间（每行 ≥90% 像素亮）
  并拉伸成 2048×1024，顺带署名写进 `src/data/moon-credits.json`。

### 11. 侧视图：黄道面合成一条线（不带透视角度）

`SIDE_VIEW_PITCH` 从 `0.1 rad`（≈5.7°）改成 **0**，`SIDE_VIEW_YAW` 也归零：
镜头正好躺在黄道面里做正交投影，于是

- 每颗行星的日心轨道、小行星带、柯伊伯带、黄道网格的环 → **全部塌成过太阳的一条水平线**；
- 行星仍然排成一串，但不再"近的高、远的低"；
- 每颗行星自己的卫星轨道盘依旧正对镜头，同心圆不受影响。

旧版那 5.7° 的俯仰会把冥王星那条 162 单位的轨道投成上下十几个单位的椭圆扇面，
整张图读起来是"斜着看一盘轨道"。另外侧视图的**指针俯仰视差也一并去掉**
（原来 ±0.028 rad 会让这条线随鼠标上下张开）。

### 12. 左键平移修复（拖动被"卡回原位"）

侧视图里有一行

```ts
current.current.target.copy(desired.current.target)   // 每帧把 target 硬拷回基准构图
```

它写在 `manualOffset` 加进去**之前**，于是左键拖出来的偏移每帧都被丢掉，
只有最后那一步阻尼把 10% 捡回来；一松手又整体跳回原构图——
手感就是"拖不走 + 一直抽搐"。现在删掉这行，让
`desired = base + manualOffset` 走统一的阻尼收敛：

- 平移与指针 **1:1**（`tools/drag-test.ps1` 量过：拖 300px = 36.21 世界单位，分毫不差）；
- 松手后**留在原地**，不再回弹；双击空白处或按主页才回基准构图。

顺带修了一处性能问题：小行星带 / 柯伊伯带 / 奥尔特云（16400 个粒子）原本写在
`computeLayout` 里，**每帧**都要重跑一遍随机数并分配三个 `Float32Array`。
它们的种子是常量，现在只生成一次，拖动与缩放明显更顺。

自检脚本：`tools/drag-test.ps1` 用一张 `?debug=1` 暴露的 `window.__atlasCamera()`
走 Chrome DevTools Protocol 真的按住、拖动、松开，断言"平移量 1:1 + 松手不回弹"，
并把拖拽前后各存一张图到 `tools/shots/drag-before.png` / `drag-after.png`。

### 13. 天体比例：保序压缩（太阳 > 木星 > 土星）

`visualScale.ts` 换成以木星为基准的**开平方压缩**：

```ts
R = 4.2 × (km / 69,911) ^ 0.5
```

得到 木星 4.20 > 土星 3.83 > 天王星 2.53 ≈ 海王星 2.49 > 地球 1.27 > 金星 1.24
> 火星 0.92 > 水星 0.78 > 冥王星 0.55；太阳单独定在 **7.5**（明显大于木星，
又留得住水星轨道 16）。旧版 `0.036·km^0.42` 让地球/木星只剩 0.37、木星与土星
几乎一样大，于是出现"太阳比木星还小、土星比木星还大"的层级错误。
内太阳系的轨道也同步放宽（水星 14 → 16、金星 26 → 28、地球 38 → 40、火星 53 → 55）。

### 14. 菜单栏分层（Scene Controls / Utility）

- **顶部正中**：卫星筛选（原"对象"）· 实时位置 · 视图
- **视图**：侧视排列 / 三维排列 / 实时全览 + 三个开关
  隐藏人造卫星及其轨道 / **隐藏自然卫星及其轨道**（新增 `hideMoons`）/ 隐藏所有轨道
- **顶部右侧**：EN / 中 · 在轨目录 · 搜索 · 指南 · 音效开关
- **删除**：黄道网格、空间天气、人造卫星透明度滑块（后者被三个隐藏开关取代）

### 15. 交互音效 + 新手引导 + 主页动效

- `src/audio/audioManager.ts`：**不引第三方库、不加载音频文件**，用 Web Audio
  现场合成 hover / click / focus / open / close / back / timeline / view 八种音色，
  方向是"仪器与机械"而不是"游戏提示音"；hover 与时间轴拖动在内部节流
  （50ms / 60ms），绝不每帧发声；第一次 `pointerdown` 才 `resume()` AudioContext。
- 新手引导（`ui/Onboarding.tsx`）：第一次落到侧视图时，左下角浮出一只**小手** +
  三行极简说明，12 秒自动淡出、用户一拖动就收起，`localStorage` 记住，只出现一次。
- 主页背景：加一条 1px 的横向扫描线与四行缓慢呼吸的遥测文字
  （`[ SYSTEM READY ]` / `EPHEMERIS // 2026` / …）。**星场本身不动**——
  背景忽明忽暗会让视觉层级崩掉。

### 16. 太阳重做：光球层 + 色球层 + 日冕流线（删掉"放射状光芒"）

- 日面改成**暖白偏淡黄的光球层**：高频米粒组织（两道 smoothstep 拉开对比度）
  + 黑子的本影/半影 + 临边昏暗（0.62→1.0）+ 谱斑。
- **橙色只允许出现在最外侧那一圈**（色球层）——旧版把橙色铺满整颗球，
  所以像一颗橘子；EUV 彩色照片也不再当颜色用，只取它的亮度当大尺度不均匀。
- **删掉了 radial ray（十六根光刺）**，日冕改成"宽而不规则的流线 + 冕洞"，
  颜色接近白（散射光本身无色），alpha 只有 0.075。
- Bloom 阈值提到 1.04 并把日面整体亮度压到接近 1：**只有米粒峰与谱斑会发光**，
  行星 / 轨道 / 卫星一律不参与 bloom。

## 更早（v5）改了什么

### 1. 真实数据与艺术坐标彻底分离

新增 `src/astronomy/visualScale.ts`：数据层只保存真实值（AU / km），
所有显示坐标都由非线性映射算出来，不再出现 `display = real × 单一比例`。

- **轨道半径**：分段单调映射（水星 13 → 火星 44 → 木星 70 → 海王星 118 → 冥王星 130），
  内太阳系明显分层，火星与木星之间留出 26 单位的断层（小行星带正好落在里面），
  外行星继续展开但不无限外扩。
- **行星半径**：0.036·km^0.42 的幂律压缩（地球 1.42 / 木星 3.90 / 天王星 1.24），
  比例关系保留。"木星明显比地球大"这件事是真的。
- **卫星半径**：0.013·km^0.42（月球 0.30，约等于地球的 21%，真实 27%），
  一颗行星的十几颗卫星才能在自己的轨道盘里排开而不互相重叠。
- **太阳半径 4.5**（对比水星轨道 13）：真实比例下太阳是水星轨道的 1/80，
  按真实画会变成一个点，按好看画会吞掉水星轨道。

### 2. 三种视角各司其职

默认进入的仍然是**共面的科普排列侧视图**：行星排成一串、黄道面几乎正对镜头，
每颗行星自己的卫星轨道盘都正对镜头、是**同心圆**（半径逐级扩大，不是同尺寸的圆叠在一起）。
间距由 visualScale 的分段映射决定，所以行星不再被压成一样大：
水星 0.72 / 地球 1.42 / 木星 3.90，屏幕上的大小差距一眼能看出来。

- **右键** → 进入 3D：仍然保持这串科普排列，只是轨道面展开成真实倾角、镜头可以环绕。
- **位置 → 真实位置** → 才切到**以太阳为中心的全局视角**：所有行星按当前时间的真实黄经摆开，
  镜头移到太阳中心并重新取景；再看一次「图示排列」会滑回那串科普排列。

### 3. Side → 3D 的解构动画 1.85 秒

- 轨道展开时长 `UNFOLD_DURATION = 1.85s`，每条轨道有自己的相位差（0~0.28）与时长倍率，
  展开是"一条条转开"的，不是整体翻一个角度。
- 相机与轨道同步走完这 1.85 秒（用户一开始拖拽就立刻交还控制权）。
- HUD 会显示展开进度百分比。

### 4. 人造卫星：靠 LOD 与命中区，不靠高光

- 标记改成普通混合（不再叠加发光），缩小尺寸、去掉刺眼的白点。
- 距离 LOD：远距离是低饱和小点（无 bloom、不闪烁）→ 中距离细圆环 + 小核心 →
  近距离才显示"太阳能板 / 天线 / 镜筒"剪影。可点击性由不可见的大命中区保证。
- 轨道 LOD：缩到总览时，一颗行星盘只有十几像素，几十圈航天器轨道与小卫星轨道
  自动退场，推近才逐层浮现。

### 5. 轨道语义按 v5 重定

- **天然卫星：细黄实线**（无缺口、无 glow）。
- **人造卫星：细实线 + 小缺口**（约 10°），缺口正好承载那颗卫星的标记与名称。
- 轨道整体更细更淡，线不再抢对象。

### 6. 聚焦布局：左景右档 + Close

行星 / 卫星 / 彗星 / 太阳聚焦后，目标固定在画面左侧约 32% 宽处，详情固定在右侧；
每个详情页右上角都有 `关闭 ✕`，关闭后回到上一级相机状态（不是回首页）。
人造卫星聚焦后中键缩放不再抽搐（取消了"直接钉死 target"与飞行插值打架的写法）。

### 7. 当前真实位置：真的会动

- 之前只翻了一个布尔值，位置映射根本没被驱动 —— 所以"点了没反应"。
  现在会真正驱动动画：单颗行星 1.3 秒、每颗晚 0.12 秒出发、全体约 2.3 秒。
- 运动是**沿着自己的轨道滑过去**（角度与半径分别插值走弧线），不是直线瞬移。
- 结束后视口回到以太阳为中心的构图（自动重新贴合缩放）。

### 8. 天体姿态用真实自转要素

新增 `src/astronomy/orientation.ts`：自转轴来自 IAU 极轴（RA/Dec），
自转角 W = W0 + rate × (距 J2000 的天数)。木星不再"极点对着太阳"；
月球、伽利略卫星、土卫六、海卫一、冥卫一按**潮汐锁定**处理——本初子午线永远朝向母体，
不会出现"月背对着地球"。行星环与卫星轨道也一并躺到真实的赤道面上。

### 9. 太阳：换掉会"缺一块"的贴图 + 黑子 + 日珥

原来贴的是 SDO 的**全圆面**照片——那是"太阳在一个黑背景上的圆盘"，
当等距圆柱贴图用必然少一大块。现在换成 2:1 的柱面日面贴图
（`public/planets/sun_equirect-2k.jpg`，Solar System Scope CC BY 4.0，经 Wikimedia Commons 取得），
整颗球完整、无缺口。

着色器里用亮度查色温斜坡重建"白中带暖"的真实日面：暗区明确压暗成黑子（本影/半影），
亮斑提亮成活动区；色球层加了针状体（spicules）扰动；日珥是贴着临边升起的等离子体弧
（14 条，高度控制在 1.0~1.5 个太阳半径），聚焦太阳或打开空间天气时强度提升到 3.6 倍。
太阳有独立档案（半径 / 直径 / 质量 / 成分 / 表面与核心温度 / 自转 / 活动周）。

### 10. 彗星系统

新增 `src/data/comets.ts` 与 `src/astronomy/cometOrbit.ts`：哈雷、67P、恩克、海尔–波普、维尔特二号，
真实的半长轴 / 偏心率 / 倾角 / 升交点 / 近日点幅角 / 周期，轨道用二体解算走真正的高偏心率椭圆。
表现分三层：核（不规则位移的二十面体）+ 彗发（越近日点越亮）+ 彗尾（永远背离太阳，越近越长）。

### 11. 视图菜单与数据出处

- `视图` 菜单：隐藏人造卫星及其轨道 / 隐藏行星轨道 / 隐藏所有轨道（三个开关都真的改变渲染），
  另有当前真实位置、黄道坐标网格，以及**其他人造卫星轨道透明度滑块**（聚焦人造卫星时默认降到 50%）。
- 黄道网格补上 XY / YZ 参考环与垂直连线，是一个真正的空间网格，不是只有一圈横向环。
- 每份详情页底部都有 `数据来源` 区块：来源名称、抓取 / 计算日期（2026-09-21）、数据版本与官方链接。
  详情内容也明显增量（质量、重力、成分、大气、发现、探测、温度、轨道要素…）。
- 中文模式下对象分类（探索类 / 观测类 / 通信 / 导航 / 空间站 / 星链 / NASA / ESA / 其他）与视图菜单全部中文化。

### 1. 交互状态机：进入 3D 之后不再退回侧视图

- 新增顶层状态 `view: SIDE | ORBIT3D`。**右键按下的那一刻**才从侧视进入 `ORBIT3D`，
  松开右键、拖拽、点击都不会把视角弹回平面；只有显式点击左上角
  `← 回到侧视图`（或 `HOME`）才回去。
- 轨道盘不再永远"正对镜头"：只有侧视图总览里盘面才跟着镜头微调；
  一旦进入 3D，轨道就冻结在它自己的真实倾角上。
- 聚焦行星 / 卫星 / 航天器之后，**取景高度归用户**：滚轮与中键拖拽都能继续缩放，
  镜头只跟随目标的 `target`，不再每帧把缩放拉回预设值。

### 2. 土星环（真凶在着色器，不在几何）

环的几何一直都在，问题是 `createRingMaterial` 的**片元着色器里用了 `modelMatrix`**——
three 只在顶点着色器声明它，于是整个 program 编译失败、环被静默丢弃。
现在行星中心通过 `uPlanetCenter` 传入，环面从"正对镜头的图谱姿态"过渡到行星赤道面，
保留卡西尼缝与环上的行星影子。

### 3. 天然卫星：真实全球图 + 可聚焦 + 轨道开口

- 12 颗主要卫星换成真实的柱面全球图（NASA / JPL-Caltech / USGS 公共领域），
  抓取脚本：`tools/fetch-moon-textures.ps1`，署名写入 `src/data/moon-credits.json`。
  非全球覆盖或带印刷标注的图（天卫、火卫一、冥卫一）不采用，那些天体保留程序化表面。
- `tools/normalize-moon-textures.ps1` 负责把裁剪黑边、拼成 2:1。
- 每颗卫星都有：屏幕空间下限（远处也看得见）、轨道开口里的高亮点、名称标签、可点击命中区。
- 轨道线区分天然 / 人造：**暖灰白实线** vs **冷灰蓝分段虚线**（低对比度，不用彩虹色）。
- 轨道开口的相位跟着天体走，天体永远落在自己的开口里。

### 4. 太阳：不再喷粒子，换成真实日面

- 常态删掉太阳风粒子喷射（只在"空间天气"里作为专题层出现）。
- 光球层用 NASA SDO HMI 白光照片（`public/planets/sun_photosphere-2k.jpg`），
  以亮度查色温斜坡重建暖白色，保留米粒组织与黑子；临边昏暗收到不会变成"月牙"。
- 光芒从"十六根光刺"改成柔和的径向辉光 + 两道极弱横向眩光；日珥强度压到原来的三分之一。

### 5. 背景稳定

- 删掉会随镜头转动的银河穹顶，星场改为固定世界坐标、无视差、无角度亮度变化。
- 开场背景重做：硬边日面 + 收紧的光晕 + 轨道弧 + 一层极淡尘埃，不再是"一团糊的东西"。

### 6. 顶部导航变成真正有功能的工具栏

`HOME｜OBJECTS（按卫星种类筛选）｜POSITION（图示排列 ⇄ 真实位置）｜黄道网格｜空间天气｜搜索｜指南｜EN/中｜VIEW｜在轨目录`

- `OBJECTS`：ALL / EXPLORATION / OBSERVATION / TELECOM / NAVIGATION / SPACE STATION / STARLINK / NASA / ESA / OTHER。
  筛选不删除对象，只把命中之外的对象退成背景密度。
- `POSITION`：`SCHEMATIC`（美术化排列）⇄ `REAL POSITION`（按时间轴年份的真实日心黄经摆开，
  每颗行星有 60ms 递进的切换延迟，不再是"串成一条线"）。
- `黄道网格`：以太阳为原点的十字坐标网格 + 每颗行星轨道半径处的 AU 刻度环，
  亮度铁律 `grid < orbit < selected object`。
- `空间天气`：太阳风暴 / 行星磁场专题入口，本轮先留空位（带说明面板）。

### 7. 三圈大尺度结构可选中

小行星带 / 柯伊伯带 / 奥尔特云现在都有命中区、档案面板与聚焦取景，选中时粒子密度提升。

### 8. 视觉修正

- 行星暗面：环境光从 16% 压到 3%，夜面不再像透亮的玻璃；大气辉光只在受光侧出现。
- 金星换成云顶（硫酸云）贴图，不再是白球或红球。
- 聚焦标识：删掉中心光晕点，改成四角 Target Bracket（进入时 250ms 展开一次，之后静止）。
- 左上角返回键与主标题不再重叠；右侧档案面板打开时，顶部导航与底部时间轴整体让位。
- 标签增加 UI 保留区与屏幕密度去重，避免文字压住 UI、互相叠字。

## 上一版（v3）改了什么

### 1. 开场不再拖沓，并且有字符解码动画

- `Intro` 现在只是视觉层，**不是 Loading 层**：`1.05s` 起 `ENTER ATLAS` 就可点，
  右下角从 `1.4s` 起常驻 `SKIP INTRO`，总时长约 `2.9s`，全程不阻塞。
- 标题用 `CharacterRevealText` 做字符解码（随机符号占位 → 逐字锁定），
  18~42ms 一档，句子总时长约 0.7s，锁定后不再闪烁。

### 2. 开场背景换成真正的宇宙

删掉了"一个椭圆 + 一个橘点飞走"那套 CSS 装饰。现在是三层视差的星场
（11,000 + 2,200 + 220 颗，视差系数 0.03 / 0.08 / 0.15）、一层程序化银河带与星云穹顶、
远处一颗主光源的日面边缘，以及几条轨道弧。全部在 `scene/StarField.tsx` 与
`scene/IntroCosmos.tsx` 里真实渲染。

### 3. 轨道姿态：平面图谱 ⇄ 真实 3D

每个天体系统同时保存两套姿态（`utils/orbitPose.ts`）：

| 姿态 | 表现 | 触发 |
| --- | --- | --- |
| `ATLAS` | 盘面正对镜头，卫星轨道是一圈圈完整的椭圆，一眼看清几层 | 默认 |
| `REAL` | 恢复轨道倾角 / 升交点 / 偏心率 | 右键拖拽开始时逐条展开 |

倾角不是随机数：按轨道类型（LEO 51.6°、SSO 98°、MEO 55°、GEO 0.4°、大椭圆 63.4°…）
给出量级，再归到 5° 一档、升交点归到 12 个方向——读起来是"若干个轨道壳"，
而不是一团乱线。凡是用类型推断出来的都标了 `syntheticOrbit`。

右下角的 `ORBITAL PLANES` HUD 会显示展开进度。

### 4. 航天器从 49 个扩到 133 个

新增 84 个档案（`data/extra-earth.ts` / `data/extra-mission.ts`），覆盖载人、气象、
遥感、导航、天文、星座、月球、火星、小天体与深空。每个对象带
`importance` 分层：1 = 主视觉对象（完整档案）、2 = 可点可搜、3 = 空间密度。

### 5. 标记不再是"一个点"

标记改成**屏幕空间恒定大小**的发光剪影（8~15px），并按种类给出不同形状：
桁架空间站、镜筒、天线+舱体、六边主镜、太阳观测环、巡视器、返回舱。
命中区和视觉大小分离——标记很小，但 15px 内一定点得到。

原来的实现把 `gl_PointSize` 除以了视深度，而正交相机距离恒为 900，
结果所有标记都被钳到 2.2px 的最小值——那才是"根本看不见"的原因。

### 6. 聚焦层级 + 以目标为原点旋转

`CameraRig` 现在有一条完整的层级：`ATLAS → PLANET → MOON → OBJECT`。
聚焦时镜头与 `target` 同时插值；落位后 `target` **每帧绑定被选中对象的实时世界坐标**，
所以月球上的卫星跟着月球跑时，镜头也一起跟过去（这是旧版"镜头留在原地"的根因）。

### 7. 卫星档案：左景右档

聚焦航天器时，对象被放在画面 **32% 宽处**，右侧 33vw 是 editorial 档案
（编号 → 标题 → 副标题 → 关键数据 → 任务始末 → 关键节点 → 距离标尺 → 任务影像），
每层 60~120ms 依次进入。行星与月球共用同一套版式，右侧给的是系统总览。

### 8. 太阳系渲染

- **太阳**：光球层（米粒组织 + 8 组黑子 + 临边昏暗）、色球层亮边、日冕流线壳、
  7 条日珥/耀斑弧、太阳风粒子，以及会被行星真实遮挡的光晕与光芒。
  日面在线性空间里只是略高于 1，亮度交给 Bloom 去做，所以"亮"而不"炸白"。
- **地球**：Blue Marble + 独立云层 + 夜灯，去掉荧光绿与深蓝高对比。
- **月球**：改用真实月面反照率贴图（旧版是程序化的橄榄绿）。
- **金星**：乳白硫酸云，不再是鲜红（旧版用的是地表雷达图）。
- **火星**：赭红压饱和；**土星环**随行星赤道面走，永远存在。
- 后处理：`EffectComposer + UnrealBloomPass + OutputPass`（HDR → Bloom → ACES）。

### 9. 大尺度结构

小行星带、柯伊伯带、奥尔特云各自有粒子带 + 引导弧 + 区域标注。
奥尔特云只在缩到最远时才浮现。三条带的出现都跟着镜头尺度走。

### 10. 时间轴恢复成真正的时间线

四层结构：连续年份标尺（每年刻度 / 每十年标签）、任务跨度横条、
发射事件圆点（按重要度分大小、分三层错开）、贯穿全线的当前时刻游标。
`▶ 回放这段时期` 会把世界时钟的倍率调到 3.4，让整张图谱真的动起来。

## 已知取舍

1. **轨道要素是按类型推断的**：数据里没有逐条轨道的 RAAN / 近地点幅角，
   REAL 姿态用量级 + 分类归档模拟，字段上标了 `syntheticOrbit`。
2. **在轨目录不受时间轴限制**：它是"此刻"的真实目录，拖到 1975 年也不会变。
3. **37 个对象没有配图**：NASA 图库里确实没有可用影像，宁缺毋滥。
4. **尺度是艺术化的**：距离按真实顺序压缩，界面上明确标注 `NOT TO SCALE`。
5. **`VIEW / ORBITAL` 目前只改变密度与线宽**，还没有做成独立的一套投影。
