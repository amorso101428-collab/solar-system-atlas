# 北京时间、大气边缘与高清地表（2026-10-03）

## 实现

- 默认模拟时钟每秒跟随系统时间，界面固定用 UTC+8；不再每 0.7 秒跳一小时、按上次数据时间循环。用户拖动时间轴进入回放，“现在”恢复系统时间。播放状态仍控制流线的动态，不会改变资料的发布日期。Open-Meteo 无偏移时间按其 GMT 接口定义解析，跨日和跨年均按北京时间显示。
- 气象图层分别显示北京时间和预报有效时间。保留过期提示，不把“检查更新”时间伪装成数据时间。已从官方 Unidata NCSS 下载 1440×721、0.25° GFS，风、降水和云量有效时间均为 2026-10-03 09:00 UTC / 17:00 UTC+8。刷新失败保留真实旧数据。
- Cesium 地表散射保留，并添加基于 WGS84 视线与椭球切线的淡蓝色边缘后处理。密度近似指数递减，没有不透明的硬球壳；跟随大气开关，退出销毁。减少全览地表的蓝色泛白。
- 高画质靠近地表（800 km 至 200 km 平滑过渡）加载 Sentinel-2 2024 EOxCloudless 10 米影像，最大瓦片等级 14。中低画质不请求高清影像；高画质更精细的 LOD、近地表自然视图关闭 FXAA，保留原图细节。
- 浏览器只请求同源 `/api/imagery/sentinel-2024/{z}/{y}/{x}.jpg`。服务端固定 EOX 源，验证坐标、4 路并发、合并重复请求、12 秒超时、30 秒失败冷却。按需展示缓存存 `.cache/sentinel-2024`，30 天失效、定期清理至约 100 MB；没有预抓整个世界。加载失败保留本地 NASA 底图。

## 边界与验证

10 米影像足以辨认城市街区、主要道路、农田和地形，但不是谷歌地球部分城市的亚米级航空影像，继续放大不能增加原图信息。未访问区域的首次高清下载仍取决于服务端到 EOX 的连接；本地底图和已缓存区域不依赖它，不能宣称已保证全国所有运营商不使用 VPN 的高清首访体验。

预览应使用 `node scripts/serve.mjs dist 4182`，开发服务器也已接入同一个影像接口。纯静态托管 dist 目录不能提供 `/api/imagery`；本次不包含部署。

新增检查涵盖中国跨日/跨年、UTC 无偏移解析、实时时钟与回放、质量档位的实际请求门槛、光晕连续衰减、影像坐标校验、并发、重复请求合并、缓存与上游失败。还运行全套原有检查、两工程类型检查和生产构建。

浏览器验收已恢复并通过：桌面全览的蓝色柔和边缘、洋流的当日北京时间、降水有效时间 2026-10-03 17:00 UTC+8、上海的高清摄影加载及相同视角的低画质降级。对照截图存于 `docs/screenshots/oct03`。类型检查及 18 个检查文件通过。

手机 390×844 下确认入口、导航、图层状态与署名可见；切换英文保留地表视角，恢复中文并取消临时视口设置。高清素材不要求 API Key，缓存缺失区域需联网。大气和高清影像没有新增浏览器运行错误；本轮未测量真实 GPU FPS。
