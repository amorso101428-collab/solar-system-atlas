# UI 融合方向样页 · 2026-10-05

## 范围与状态

只做地球档案的代表性预览，等待视觉方向确认；没有上传或替换正式站。通过 `?ui=heritage` 激活，普通 URL 保持当前 UI。样式文件 `src/styles/heritage-preview.css` 的所有规则都限制在预览属性下。

本机预览：http://127.0.0.1:4197/solar/?view=atlas&body=earth&lang=zh&boot=0&ui=heritage 。运行方式：先 `npm run build`，再 `node --dns-result-order=ipv4first scripts/serve.mjs dist 4197`。预览服务需保持运行。此 localhost 地址不能直接用于其他设备。

## 视觉取舍

- 恢复旧版完整、约 96% 不透明的暖黑背景板、暖金边框与明确的标题/正文比例。
- 外层保留轻玻璃：桌面模糊 12px，手机 6px。静态长文不逐段叠加模糊与小卡片。
- 大标题用既有字体令牌，桌面 38px、手机 32px；暖金竖线标识档案身份。正文 14px，段落和数据表恢复连续排版。
- 海洋入口、观察控制保留内嵌分组，其他文章章节主要用分隔线组织。按钮逐项处理行高、内边距、居中和长标签换行。
- 手机目录始终不透明，不因 hover/focus 露出后面的文字。内部章节导航横排，展开/收起按钮等宽，优先让正文进入视野。
- 不改变三维场景的日常摄像机、卫星地图、渲染性能策略与现有手机可视区域边界；移除进入地球前的延时黑幕和相机俯冲，改为原生链接直接进入。

## 本轮反馈修订：目录间距、动效、地球入口

- 目录列表原本没有桌面纵向 gap，造成选中和 hover 背景贴合。现在桌面纵向和手机横向都是 8px；目录按钮不再被 flex 压缩，长标题自然换行。
- 加入 180ms 控件反馈和 280ms 面板淡入，只动 DOM 的颜色、边框、阴影、透明度与 1px 按下反馈，不逐帧改变模糊、面板尺寸或场景。
- 标题栏新增“动效 · 自动 / 开 / 关”循环开关。自动遵循系统减少动态偏好；用户明确开启只覆盖预览 UI，场景仍遵循系统偏好。`&motion=full` 可直接预览开启状态。
- 旧标签页检查接口两次超时，无法取得其卡死堆栈；新页上旧入口可以成功进入地球，尚不能认定原标签页卡死的精确根因。已取消会阻挡全部交互的 Solar 出发黑幕，以及依赖 100/1400ms 回调的导航。入口是可独立访问的新页面链接，偏好保存失败不会拦截导航。地球模型双击也改为立即进入同一目的地。
- 只在点击时读取观察方向，不再每帧执行俯冲相机更新。进入地球的实际坐标为 99.297°E / 28.448°N；返回保留语言、年份、轨道模式、heritage 预览及显式动效选择。
- 1440×900：目录项实测约 8px 纵向间距；点击“探测”后 aria-current=location。关闭动效后 transition=none。
- 320×568 英文、375×667 中文：开关和关闭键高约 44px，不重叠；档案 scrollWidth=clientWidth，目录横排 gap=8px。最终样页实测 transition-duration=0.18s、animation-duration=0.28s。
- 已实际点击中英文入口，看到可操作地理地球、卫星影像和导航控件，而非只检查跳转 URL。英文返回后 URL 保留 ui=heritage&motion=full。最终中文地球页没有控制台 error。

## 追加反馈：实际用户点击链接仍无反应

用户确认“探索地球”点击无反应，但关闭、动效和目录正常。因此上一轮的调试接口超时不能证明整页冻结；不要把这件事表述成已定位页面卡死。当前可检查的新页没有错误，也没有入口 pointer-events 禁用，仍未取得原标签页的故障堆栈。

上一轮原生链接方案不足以覆盖用户的实际点击路径。本轮恢复 `type=button`，`onClick` 直接调用 `goToEarth(language)`，由 `window.location.assign` 同步导航，不依赖链接默认行为、黑幕或计时器。只有场景里的地球双击保留 focus guard，档案里的明确入口不会被隐藏状态判断静默取消。访问信息保存仍是可失败的可选步骤，观察方向仍在导航前读取。

新增导航行为测试确认：准备和导航同步执行、坐标先捕获再生成目的地、准备抛错后仍会跳转。根项目和 Solar 类型检查、26 项回归检查、本地构建再次通过。

使用与用户完全相同的返回地址（`return=ocean&year=2026&unfold=1&ui=heritage&motion=full`）刷新最新构建后，实际点按钮进入地理地球；返回后使用 Enter 再次进入，看到卫星地球和导航控件，没有控制台 error。截图 `earth-button-entry-from-return.jpg`、`earth-button-entry-second-visit.jpg`。

原用户标签页 6 的自动刷新仍在调试接口处超时，不能确认它加载了最新脚本；需要用户手动刷新或重新打开预览，再确认真实鼠标点击是否解决。内置浏览器可能对链接默认行为进行处理只是推测，不能当成已证明根因。没有发布云端。
