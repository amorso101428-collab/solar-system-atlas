# 地球与太阳系统一修复（本地）

## 已实施

- 两入口默认使用 heritage 主题，并最后加载同一份 unified-ui.css。保留原场景与移动阅读视口。
- 地球菜单、搜索结果、资料库等外壳恢复完整深色底板；内部取消重复模糊，增加间距与文本对比。
- 搜索栏使用 44px / 自适应输入 / 44px 三列，SVG 放大镜与 CSS 箭头不依赖字符基线。
- 界面淡入 280ms、按钮反馈 180ms。自动遵循系统减少动效；用户明确选择开启才覆盖 UI 动效。选择通过可选 sessionStorage 跨页面保持。
- 两工程分别使用各自 React/Zustand，仅共享无框架的动效策略，避免双 React hook 报错。
- 本地影像在 6,000km 开始淡入，3,000km 完全显示；原来 2,855km 仅约 1% 透明度，现在是 100%。在线卫星影像在 2,000km 内按需加载；失败仍保留本地照片，不切换白色街道地图。
- 静止时提高画布像素预算，保留原拖动预算与恢复机制；静止自然视图不额外使用 FXAA 模糊。
- 左右键、触控拖动均绕地心旋转，不再在屏幕平面中平移相机。保留滚轮和双指缩放、中键单击回到全览。

## 验证

- 浏览器桌面区域视图（2,855.2km）确认地表细节、搜索对齐、菜单与资料库整块背景。
- 390px 手机资料库、地球阅读档案与 320px 窄屏检查，面板正文无横向溢出。
- 不加 ui 参数的太阳系地球档案确认相同默认主题；实际点击探索地球成功跳转。
- 实际搜索香港并进入约 7.3km 高度，确认 Esri 卫星／航空照片已加载，未切换白色街道图；该验收页未出现控制台错误。
- 最终 npm test、npm run typecheck、npm run typecheck:solar 均通过。
- 相机约束由打包 Cesium 的真实 Camera/Matrix 计算回归验证；没有把未实际执行的浏览器右键拖动当作视觉证明。
- 保存截图位于 qa/unified-ui-20261005/。

## 后续：章节目录降低密度

- 顶部横向小标签方案仍过于紧凑，现已替换为可折叠章节选择器：收起显示当前章节，展开后纵向逐行列出完整标题。
- 目录距面板标题 24px，正文起始留白 32px；条目至少 64px 高，内边距 16px，条目间距 12px。
- 显式覆盖旧主题的 9px span 字号与目录整体透明度：章节标题 15px，展开列表使用不透明深色背景。
- 弹出列表高度受阅读面板实际剩余空间约束，长标题允许换行，避免最窄手机屏幕把末项裁掉。
- 共用 ArchiveContents 的地球阅读档案统一生效；章节选择后自动收起，支持点外部或 Escape 收起。
- 本轮浏览器实际验收桌面、390px 和 320px 手机尺寸，检查了末章选择与自动收起；截图命名 earth-chapters-spacious-*。
