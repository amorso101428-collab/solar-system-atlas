# 地球工具浮层（2026-10-03）

所有地球工具统一使用透明面板外壳，包括图层、资料库、探索路径、潜水、地球阅读档案、物种档案、剖面、位置查询及设置。菜单与搜索结果也使用透明容器，玻璃背景仅保留在独立项目卡片和总纲卡片上。摄影弹窗移除整屏黑色遮罩。

根布局统一使用 `has-overlay`，不再根据面板添加会改变地球画布尺寸的 `has-panel` 或 `has-archive`。打开、切换、关闭面板不缩放画布或调整相机；选择地理对象时仍保留已有定位功能。浮层入场仅改变透明度和小幅纵向位移，支持减少动态效果。

保留档案总纲、内部滚动、返回此前工具、步骤控制、中英文切换和亮色街道底图上的深色文字。手机下拉菜单的显示层级高于搜索框，避免入口点击被遮挡。
