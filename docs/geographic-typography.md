# 地理标注字号与显示层级（2026-10-03）

独立标注使用网页的 `--sans` 字体，固定 12 CSS px。相机缩放只改变投影位置、候选层级和透明度，不改变字号、字距或文字比例。降低阴影强度，洋流名称使用低饱和暖色。

大洲与大洋在远景显示，区域尺度逐步退场；国家／地区在区域尺度显示；主要城市先出现，其余城市与小城镇在更高缩放级别出现。相邻层级边界使用渐变透明度过渡。主要城市在本地贴图模式下仍可保留至近景。屏幕空间碰撞与界面避让保留，桌面最多 48 个、手机最多 22 个独立标注，小屏幕按面积进一步降低数量。字体加载完成后重新测量文本宽度。

国内 GeoQ 街道底图是带文字的合成 PNG 瓦片，不支持动态拆分文字图层。其路名无法由网页 CSS 改成 Inter／苹方，也无法完全固定屏幕字号。街道底图完整加载后，避免叠加重复的独立城市、道路等标注；独立海洋、地貌和洋流名称继续使用网页字体并适配浅色地图。保留已获用户同意的国内街道底图与现有归属说明，没有重新启用国外在线底图。

接口依据：https://thematic.geoq.cn/arcgis/rest/services/ChinaOnlineStreetGray/MapServer?f=pjson
