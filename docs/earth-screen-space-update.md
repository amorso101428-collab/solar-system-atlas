# 地球交互、云图与屏幕空间布局修订 · 2026-10-02

本轮处理左下角重叠、鼠标方向、云图放大细节、大气硬边、标注字体、流线密度和洋流名称。原太阳系入口、音乐开关、双语、资料库及数据管线保留。

## 实现

- 地球 HUD 用一个自动排布的底部信息栏，以及位于其上方的状态栈。ResizeObserver 根据实际信息栏高度为状态、时间控件及手机导航预留空间；展开时间栏时只扩展状态栈。Cesium 自带署名通过公开 creditContainer 接口进入这一排布，Logo 最大 65×14px，保留原链接和 Data attribution。清除旧的多套固定 bottom 偏移规则。
- 左键按屏幕右、上方向向量平移相机，不改变朝向。右键旋转完整相机框架，围绕画布中心选中的地表点旋转；四个拖动方向与太阳系一致，直俯视角也能向两边旋转。中键单击复位，移动超过 5px 的中键拖动不触发复位。保留 AngularMomentum 的缓慢调整、快速释放惯性及新一轮按下立即制动。
- 云图更换为 Solar System Scope 原生 8192×4096 合成。预处理透明蒙版，生成 2K/4K/8K 三层、512px 瓦片和 2px 接缝边距。浏览器不运行整图 getImageData。并发最多 2 张，先显示父瓦片，四张子瓦片就绪后统一替换，避免两层云叠加变白。镜头移动时保留已缓存细节，暂停新细瓦片请求；停止后继续细化。高、中档近景可到 8K，低档以 4K 保持较小的开销；缓存采用 LRU，当前覆盖保留。HTTP WebP 类型、ETag、版本参数及一天缓存已核实。
- 删除额外的硬边椭球光晕，统一 Cesium 原生天空与地表大气的 Rayleigh/Mie 散射参数。空气密度按 8km / 1.2km 尺度高度指数衰减，逐像素计算天空散射。
- 地理标注统一 Inter/PingFang 等 UI 字体，桌面 11px、窄屏 10px；删除大洲、大洋名称下重复的类别副标题。英文大洋和洋流名称使用普通标题大小写。
- 风场、洋流按屏幕网格播种，保持 1.05 CSS px 线宽和受控的屏幕轨迹长度。放大后不会把数千条全球粒子全部挤进当前区域。整条轨迹的屏幕格子参与避让，减少汇聚处相互叠加。风场最多 650 个种子，洋流最多 520 个，实际可见数量受面积、海陆和轨迹碰撞限制。窗口尺寸变化后重新分布。
- 命名环流以现有档案路径为示意，按半度采样和现有海陆掩膜裁切，删除孤立小片段并在日界线处拆分。名称随路径投影、缩放和语言变化，在资料区及其他名称周围避让；关闭地理标签时，开启的洋流图层仍保留自己的名称。点选命名路径可打开对应档案。

## 素材与边界

官方来源：[Solar System Scope textures](https://www.solarsystemscope.com/textures/)。下载文件：https://www.solarsystemscope.com/textures/download/8k_earth_clouds.jpg 。授权 CC BY 4.0；署名、改动及源文件 SHA-256 记录在 public/earth/cloud-tiles/ATTRIBUTION.md 和 manifest.json。原文件在 assets/sources/earth-clouds-8k.jpg；scripts/build-cloud-tiles.py 可重建瓦片。

这仍是保存的全球摄影合成，不是实时云图，也不提供源图以外的新细节。云层 45km 为原有导航展示高度，不代表各处云顶的实测高度。命名洋流路径为科普示意，流场保留“模拟”标识。未申请新的 Google 服务权限、没有部署。

## 验证

- 两个应用 TypeScript 检查、scripts/check.mjs 和生产构建通过。
- 使用项目实际打包的 Cesium Camera/Matrix：验证右键四向、直俯视、地表附近无起步跳动、旋转距离不变，左键平移且朝向不变，中键单击/拖动区别，以及惯性、停止和清理。
- 检查所有 168 张云图瓦片存在、日界线拆分、海陆路径裁切、湖泊大小的命名片段剔除，及两种观察尺度下的屏幕运动和线宽配置。
- 浏览器检查 1440×900、1024×768、390×844，以及 844×390 横屏，中文及英文时间栏、底部来源、导航和标注。核实云层近景实际覆盖为 level 2（8K），不是仅更改状态文字。记录风场近景种子 650、显示约 438 条，线宽仍为 1.05px；数量随随机播种和避让变化。
- 浏览器未捕获新增 error/warn。气象上游不可用时继续保留预报，并显示保存数据状态。未测量真机手机 FPS 或模拟慢网速度，不宣称固定帧率或所有网络下即时加载。
