# 地理地球引擎重构 · 2026-10-02

本轮替换海洋端的 Three.js 单球与中心 25 张贴片方案。活动入口改为 `GeospatialEarth.tsx`，使用 CesiumJS 1.132.0 的 WGS84 地球、影像四叉树、地形瓦片、屏幕误差细化、请求调度、近远裁剪和地形碰撞。太阳系与深海首页仍使用各自的 Three.js 场景，不同时渲染。

## 影像清晰度

Esri World Imagery 从官方服务元数据建立层级；加载整个可见视野，地表像素变大时自动取更细层级，视野移动时取新瓦片。父层影像在细层未加载时保留，内存瓦片缓存上限 300，正常视野渐进细化。没有固定 25 张窗口和 17 级上限，不会把 4K 全球图冒充街区影像。各地原生影像质量、年份和最高层级不同，放大超过实际数据分辨率不会产生新细节。

高、中、低档地形屏幕误差分别 1.2 / 2 / 3 px；显示像素比按设备限制为 2 / 1.5 / 1。避免高像素比屏幕只按 1 倍渲染。在线数据失败时保留项目内的全球底图，提供重试状态。

## 地形与导航

Mapzen Terrarium DEM 真实高程经重投影后构成完整地理四叉树和山地网格，不以影像亮暗生成高度。源 DEM 使用 Web Mercator，仅覆盖约 ±85.05°；极点几何使用参考椭球，极区影像使用已保存的太阳系冰盖纹理柔和过渡。避免源网格缺口和极区黑洞，不把极区回退称为真实高程。默认开启「真实三维地形」，可独立关闭为椭球。当前用户最小视点高度为地面之上 30 米；引擎碰撞及载入高程后的二次高度校正保护镜头。山地高程随层级细化，原生精度各地不同。

- 左键拖动：沿地表平移；滚轮：朝指针位置缩放。
- 右键拖动（与太阳系端一致）、Ctrl / Shift + 左键拖动、鼠标中键、双指：倾斜或绕当前位置旋转。
- 双击地表：靠近点击位置；滚轮和指针输入中断飞行动画。
- 右侧按钮：连续放大、缩小、俯视 / 3D 倾斜、北向复位和全球复位。
- 搜索：选择地点平滑飞入，国家与城市按边界范围选取视距。内置城市、山地及海洋目的地；其他名称提交搜索后查询 OpenStreetMap。无持续自动补全请求；连续查询限速。
- 也可输入 `纬度, 经度`（与 Google Earth 的坐标顺序一致；首项大于 90° 的旧经度优先格式仍兼容）。画布键盘支持 `+`、`-`、`N`、`R`、`T` 与方向键，Shift + 方向键转向。
- 底部显示中心经纬度、视点高度、地表高程和比例尺；后台地表细化有状态。

直接视角链接示例：`/?view=globe&lang=zh&lon=121.4905&lat=31.2292&range=9000&pitch=-55`。参数范围校验；旧地图 / 深度 / 太阳系深链接兼容保留。

## Google 摄影测量三维城市

已经接入 Cesium 的 `createGooglePhotorealistic3DTileset`。`public/earth-config.json` 内 `googleMapsApiKey` 默认为空，因此本次运行**不是 Google 的三维城市摄影数据**。无需 Google 或 Cesium ion 令牌即可使用现有 Esri 影像和地形。

如果已有获授权、启用 Map Tiles API（名称搜索还需 Geocoding API）的浏览器密钥，在本机配置文件写入后重新构建。密钥应限制访问来源和 API；配置会发给浏览器，不能放服务器私密凭据。本项目没有创建账户、启用计费、申请服务或部署。

有 Google 配置时，三维摄影 tileset 自动接入，保留引擎强制署名；地点查询改为 GoogleGeocoderService，不混用 OpenStreetMap 地理编码。科学分析开启时隐藏城市 tileset，并使用球面数据和底图；退出后恢复。加载失败保留卫星影像。由于未提供密钥，此分支通过类型检查，尚未实际请求 Google 数据。真正摄影测量三维建筑及 Google 街景不是当前无密钥版本已经完成的内容。

## 科普图层保持

洋流、风场、降水、海底着色、暖寒流、经纬网、海岸线、环流示意、地名和潜点移植到同一个地球。洋流检查海陆掩膜，风与洋流使用球面流迹；气象数值及来源不变。科学数据分辨率与底图分辨率分别说明，气象网格已从 2° 提升到原生 0.25°，1440×721，仍是预报产品而非雷达。

云层独立在约 10–13 千米高的椭球壳显示，白色发光材质和更实的透明度避免灰暗。自然云层只使用保存的 Solar 摄影透明度纹理，去掉暗背景和预报产生的灰膜；GFS 云量改为独立百分比色彩图层，开启时隐藏摄影云层。页面明确标示自然云层不是实时卫星实拍；靠近地表隐藏，数据分析时按原用户偏好隐藏 / 恢复。大气为 Cesium 实时散射，程序星点随世界视角变化。点击海洋、洋流、潜点和空白星空仍可打开原双语阅读档案。

## 自动更新与科学分辨率

Node 预览 / Vite 中间件每小时从 Unidata 获取原生 GFS 网格，客户端每分钟查询同源端点。二进制和元数据按同一下载版本配对，保留最近三版；拒绝较旧有效时间、缺失值和截断文件，断网保留旧数据并标示更新不可用。静态服务器无此中间件时读取项目保存快照。

风场高 / 中 / 低档为 6000 / 3600 / 1600 条轨迹，洋流为 4800 / 2800 / 1300 条；优先播种当前视野，洋流整条轨迹检查海陆掩膜，日期变更线拆分。降水按连续数值双线性采样，显示纹理为 2880×1440（高）或 1440×720（中 / 低），边界渐变透明；显示插值不宣称提高到 0.25° 以上的气象精度。

全球洋流仍使用现有模拟 / 已发布数据管线；每 30 分钟检查项目已发布清单，有较新时间时更新。此次公开全球 HYCOM 获取尝试未取得可用数据，默认仍标“模拟”。位置海流查询为独立预报来源。
