# 地球界面细节调整 · 2026-10-03

顶部左侧依次为主页、返回地球系统、地球、图层、资料库、探索路径、潜水。音乐、语言、设置在右侧同一行，搜索位于其下方。保留原太阳系项目的玻璃面板、按钮和交互状态。

底栏延伸至可用画布右缘；导航按钮位于底栏上方，随底栏实际高度和右侧面板空间调整。小屏保留 44px 点击范围，使用工具菜单和分组排布；短横屏将导航按钮横向排列。搜索、面板和图例内部可滚动。

降水由单张全球栅格改为 Cesium 可见视野瓦片，按缩放请求细节。高、中档生成 512px 瓦片，低档 256px，最高层级分别为 5、4、3。缓存限 32 张，同时生成限 2 个任务，行间让出主线程；切换图层后取消任务并释放资源。

对降水数值采用正权重三次 B 样条重建，再映射强度色带；避免把低分辨率彩色图直接拉大，也避免插值产生虚构的强降水极值。雨区边界连续，蓝、青、绿、黄、橙、红、紫对应由弱到强，图例保留 mm/h 单位。

数据来源仍为已有 NOAA / NCEP GFS 0.25° 预报网格。显示重建不会提高真实预报空间分辨率，局部峰值在重建时会有所平滑。沿用北京时间、预报有效时间、自动更新和保存数据状态，没有替换数据源或改变模拟洋流标识。

验证：项目与太阳系集成的类型检查通过；19 组现有及新增检查通过；生产构建通过。浏览器检查 1440×900、1024×768、390×844 和 844×390，中英文切换、设置侧栏、导航缩放和雨区放大均可用，未观察到新增运行错误。
