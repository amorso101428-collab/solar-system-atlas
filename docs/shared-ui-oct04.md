# 太阳系 / 地球共享 UI 验证记录 · 2026-10-04

> 此版外观被用户否定，已撤回其统一字号、44px 桌面按钮和蓝灰玻璃覆盖。当前版本以文稿中的太阳系原工程为基准，见 [原版 UI 恢复记录](original-solar-ui-oct04.md)。下文与截图仅保留为修改历史。

两层入口最后加载同一份 `src/styles/atlas-ui.css`，统一字体、字号、控件尺寸、圆角、磨砂材质、悬停反馈和弹性按压。桌面采用相同的仪表式鼠标指针，触屏保留原生操作；悬停粒子继续共用现有粒子实现。指针停止运动后停止动画循环，减少空闲开销。

所有工具外层透明，玻璃集中在项目与阅读卡片上。打开档案、资料库、设置、音乐和手机菜单不会更改画布大小、相机比例或缩放。桌面阅读侧栏位于卡片左侧；太阳系时间栏避开档案，但场景始终占满视口。临时工具关闭后恢复原档案。

地球“地球 / 图层”菜单采用 600ms 向下展开，条目轻微错峰。只展开文字和图标，按钮命中区域保持稳定，避免动画期间快速点击穿透到地球。“减少动态效果”会关闭展开与入场动画。

## 已完成验证

- 地球与太阳系 TypeScript 类型检查通过。
- 项目现有 21 项检查通过。
- `scripts/build.mjs` 生产构建通过；预览服务使用最新 `dist`。
- 1440×900：两层顶部按钮为 44px 高、12px 圆角、11.5px 导航文字；档案宽度约 518px、顶部 140px，场景保持完整视口。
- 390×844：地球中文 / 英文资料库无横向溢出、入口可达；太阳系手机菜单使用项目已有 `device=phone` 预览方式检查。
- 实际点击验证地球下拉菜单、快速点选蓝色星球、图层、档案返回、语言切换、减少动态效果与太阳系进入地球。
- 检查期间两层浏览器错误日志为空。
