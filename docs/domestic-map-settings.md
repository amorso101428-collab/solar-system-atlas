# 国内地图与透明设置 · 2026-10-03

默认配置 `mapSource: "geoq"`：远景使用随项目保存的地球摄影贴图，高画质近地浏览加载国内 GeoQ 公开街道底图。该图源是街道地图，不是高清卫星摄影。公开服务元数据见 [GeoQ ChinaOnlineStreetGray](https://thematic.geoq.cn/arcgis/rest/services/ChinaOnlineStreetGray/MapServer)，包含 0–19 级瓦片及提供商署名。

浏览器请求同源 `/api/imagery/geoq-gray/{z}/{y}/{x}.png`，后台只连接固定国内域名 `thematic.geoq.cn`。沿用并发 4、去重、PNG 格式校验、100 MiB 按需缓存及失败回退；没有批量下载。已实测官方接口和本地代理均返回 HTTP 200、256×256 PNG。生产地球及旧 Three.js 图层不再调用 EOX、Esri、Google 在线地图；搜索与地名使用项目内数据。

如需国内高清卫星地表，设置 `mapSource: "tianditu"` 并填写自己的 `tiandituKey`。没有 Key 时使用 GeoQ，不伪造授权、不借用他人 Key。天地图接入说明见 [官方申请说明](https://lbs.tianditu.gov.cn/server/search2.html)。本次保留已有本地地球贴图及其来源署名；它们不会触发境外瓦片请求。天气数据管线不在此次地图源替换范围内。

本地台湾标注统一为“台湾 / Taiwan”，同时修改生成脚本、地图显示和搜索结果的名称规范，避免更新资料后恢复旧名称。

设置使用独立浮层状态，不再使用挤压地球画布的侧栏状态。浮层外壳、标题区透明，只有设置项目保留透光玻璃卡片；浅色街道地图下自动使用深色文字。入场仅有轻微位移与渐显，无缩放。减少动态效果时取消入场动画。手机保留内部滚动与关闭入口。

验收截图位于 `docs/screenshots/oct03-domestic/`。浏览器测量设置打开前后画布均为 1280×720，视点高度不变；国内街道地图及“台湾”标注已实际显示。390×844 手机面板可以滚动到画质滑块和减少动态设置，未观察到新增运行错误。

项目及太阳系集成类型检查、19 组检查与生产构建通过。本地后台已重新启动并启用新地图接口，预览仍为 `http://127.0.0.1:4182/`。本次未部署。
