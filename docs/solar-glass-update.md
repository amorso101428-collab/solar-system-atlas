# 2026-10-03 · 太阳系玻璃 UI、画质滑块与接缝修复

## 实现

- 从已集成的太阳系 `styles/optical.css` 提取同一组玻璃材质：暖金 / 青灰 / 紫灰边缘、深色半透明填充、12px 控件圆角和 22px 档案圆角。两套工程现在共同导入 `src/styles/optical-glass.css`。地球导航、搜索、图层、资料库、档案总纲、设置、底部信息和天气图例采用这组样式，保留之前已修复的自适应布局。
- 原太阳系 `UIParticles` 的发射、悬停 / 点击 / 焦点反馈、粒子颜色与轨迹完整移入 `src/lib/uiParticles.ts`；两边的 React 包装组件分别使用各自的 React 实例。粒子上限 160，空闲时停止 RAF，隐藏窗口及减少动态效果时清空，卸载时移除监听器。
- 新画质滑块使用低 / 中 / 高三个吸附位置。拖动过程连续移动玻璃镜片，松手才应用画质，避免每个 pointermove 都重新创建场景图层；支持点击档位、方向键、Home / End、拖动取消、触屏 pointer capture、中英值说明和减少动态效果。吸附使用弹性曲线，拖动时镜片轻微拉伸。
- 摄影云层在眼高 2,000km 以上完整显示，在 2,000–350km 之间以 smoothstep 渐淡，在 350km 以下不再遮挡地表。保留用户云层开关；返回轨道视角后自动恢复。淡出后停止请求新的细节云瓦片，摄影来源与非实时性质仍明确显示。
- 小屏幕抽屉打开后隐藏会被其遮挡的场景错误浮层；设置面板保留影像 / 地形失败信息和重试入口。

## 截图中竖向分割的处理

截图中心接近太平洋的 ±180° 经线。此前高斯环流与经度噪声不具备周期性，跨日期变更线后速度和方向突变；流线又在经度跳变时被主动切断。现在环流使用周期高斯及整周傅里叶噪声，水掩膜索引循环，Cartesian 流线和命名洋流路线可连续跨过该经线；洋流选取和暖寒流路径距离也采用同一套经度规则。

轨道视角改用完整的 Solar System Scope 摄影，避免在线影像尚未全部细化时出现一侧高分辨率、一侧低分辨率的色差块。眼高 3,000–600km 渐变接入原有 Esri 高清影像；600km 以下仍使用高清分块地表及原有地形方案。没有用放大旧图代替近地高清影像，没有增加外部素材或新许可证。云图仍使用上一轮已保存的原生 8K 透明瓦片。
