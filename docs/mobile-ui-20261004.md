# 手机 UI 修复与验收 · 2026-10-04

## 根因

共享 UI、旧 responsive 样式和音乐样式对同一面板重复定位。手机档案同时使用固定上下边界和旧 BottomSheet 的 translateY，导致正文落到屏幕外，固定目录却停在原位置。地球面板的绝对目录、移动端导航、搜索、竖向地图工具条与页脚也没有统一保留空间。减少动态效果时，首页动画被取消，但入口按钮仍保持初始透明度。

## 修复

- `src/styles/mobile-ui.css` 最后载入，并限定手机或紧凑窗口范围。正常桌面宽度的既有三维场景、地图源和交互保留。
- 手机导航、底部栏和阅读面板使用统一边界与安全区；正文独立滚动。手机宽度窗口不再因鼠标指针被强制使用桌面导航。
- `MobileReadingSheet` 不再平移整个档案；保留标题栏下拉关闭。旧实现文件留存但不再挂载。
- 档案关闭键、横向目录与正文不再重叠；目录点击使用手机偏移值。
- 菜单、搜索、作者、音乐、指南、任务目录统一不透明玻璃背景；输入字体 16px，主要操作触控区域至少 44px。手机指南改为真实触摸手势说明。
- 手机时间轴明确显示展开/收起状态，事件列表独立滚动；打开其他面板时隐藏底层时间轴。
- 地球工具条改为横排，图例默认折叠；搜索、导航、页脚各占独立区域。设置与地球文章使用标题/目录/正文网格，关闭键始终可达。
- 可视视口高度跟随软键盘变化，但键盘不参与 Solar 横竖屏方向判定。减少动态效果模式下首页入口仍可见。

## 浏览器验收

通过 Codex 浏览器视口测试，而非实体 iPhone/Android 测试。没有宣称覆盖所有系统浏览器、虚拟键盘行为或全部文章内容。

| 视口 | 核验 |
| --- | --- |
| 320×568 | 地球导航和设置；设置正文 166px 可读区、730px 内容可滚动；音乐面板无水平越界 |
| 375×667 | 火星档案；面板 top=64 / bottom≈608；正文完整可滚动；搜索 16px 输入、结果正常；目录点击能定位 |
| 390×844 | 地球工具横排、图例折叠；地球文章目录不遮正文，第三章定位到正文顶部；首页入口 opacity=1；时间轴、菜单、任务目录和触摸指南正常 |
| 430×932 | 不加 device 覆盖参数也自动采用手机布局；地球档案无水平越界 |
| 844×390 | 手机火星档案 full-width 阅读；地球文章右侧阅读、左侧页脚；目录与正文分区 |
| 1440×900 | 自动仍为 desktop；火星档案恢复既有右侧布局，无页面水平越界 |
