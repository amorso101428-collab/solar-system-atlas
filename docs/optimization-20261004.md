# 2026-10-04 本地优化

## 发布文件整合

同版普通构建 `dist`：1,518 个文件，约 199.5 MB。
整合构建 `dist-pages`：62 个文件，约 173.4 MB；32 个不超过 4 MiB 的资源包还原 1,487 个资源，189 个文本资源使用 gzip。所有还原资源的 SHA-256 与原件一致，图片未降质。浏览器不使用的原始 NetCDF 仅从生成的发布目录省去，`public` 中原件保留。

`dist-pages` 依赖 Cloudflare Pages 的 `_worker.js`，不能直接换成普通静态文件服务器。普通静态托管请使用 `dist`。本地整合版预览：`npm run preview:pages`；可指定端口：`node --dns-result-order=ipv4first scripts/serve-pages.mjs dist-pages 4192`。本次未部署线上站点，原始 `release-pages` 未改。

## 地球拖动

- 鼠标输入合并到 Cesium 每帧更新，单次平移缓存地表拾取和换算比例，复用向量／矩阵对象。
- 拖动时降低渲染像素预算和地表细化精度，停止后恢复；DPR 不再成倍放大 GPU 负担。保留惯性、慢速停止、触摸缩放与相机高度限制。
- 云层仅在视野／瓦片变化时规划，避免反复开关所有透明几何。地名投影节流，HUD 位置读数节流；拖动期间暂时关闭面板背景模糊。
- 去掉 HDR 和重复抗锯齿开销。实际流畅度仍取决于显卡、浏览器和影像网络，不承诺固定帧率。
- 对 Cesium 漏发 moveEnd 增加兜底：相机稳定 450 ms 且操作／惯性结束后恢复静止画质。
- 用实际世界坐标位置／朝向判断运动，不依赖分辨率变化可能触发的 moveStart；预览中非哈希脚本不长时间缓存。

## 卫星影像与标题

近景默认切换到 Esri World Imagery 卫星／航空摄影，同源接口限源、限级别、限响应大小并缓存一天；失败保留本地摄影底图。不是实时影像，不再默认加载 GeoQ 白色街道图。天地图 Key 与显式 GeoQ 配置保留。

行星、太阳、彗星、任务对象、区域档案的大标题共用玻璃背景；地球阅读与资料库等标题也统一背景，保留原字体和层级。
小于 700px 的档案改用顶部横向章节目录，避免侧边目录将正文挤成窄栏。
