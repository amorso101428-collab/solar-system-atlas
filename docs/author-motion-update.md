# 署名与旋转手感更新

## 本次修改

- 首页移除“共创 / CO-CREATOR”，以两行五列网格排列版权、作者名和平台链接。ESSELANO 与 Quincy. 使用同一字体；平台顺序均为小红书、哔哩哔哩、抖音。保留原作者版权及所有现有外部链接。
- 太阳系共用 CameraRig 的横向旋转从 0.0016 降至 0.00075 rad/px，纵向从 0.0022 降至 0.00085 rad/px；首页和触屏同步降低灵敏度。因此所有行星、卫星及对象聚焦视角使用同样的手感。
- 两套地球/太阳系渲染器共用按时间采样的惯性模型。取最近 90ms 的拖动速度；慢于阈值或松手前停顿超过 100ms 时不继续转动。快速松手以指数摩擦减速，限制最大速度，并在松手时损失部分动能，避免过长滑行。
- 地球左键移动视野，右键围绕屏幕中心的地表点旋转。近景拖动灵敏度随视点高度降低；右键保留当前地表支点和距离，避免第一次拖动跳转。滚轮及双指缩放、现有地形避碰和高度下限继续生效。
- 新按下、滚轮、导航、切换对象、取消手势或窗口失焦都会停止旧惯性。减少动态效果模式下关闭松手惯性。

## 验证

- 根项目与太阳系子项目 TypeScript 检查通过；生产构建及现有回归测试通过。
- 惯性测试覆盖快拖、慢拖、停顿、取消、最大滑行、减少动态效果和 30/60/120fps 一致性。
- 使用项目随附 Cesium 1.132 的真实 Camera 和矩阵测试地球控制：快速拖动后渐停、慢拖静止、按下制动、近景右键无跳变、保持地表支点距离、取消和资源清理。
- 浏览器验证桌面和 390×844 手机署名。两行作者及各平台的横坐标一致，页面无横向溢出。
- 浏览器验证地球近景：松手后的经度从 112.1725°W 继续至 112.2410°W，视点高度保持 65.7km，说明惯性实际作用于相机而非 UI。火星聚焦旋转后档案保留，未出现浏览器运行错误。
