# HUMAN ARTIFACTS

交互式太阳系图谱：探索行星、卫星、人造航天器与实时在轨对象。

[在线体验](https://solar-system-atlas.pages.dev/)

## 功能

- 3D 太阳系与真实轨道倾角
- 行星、卫星和航天任务档案
- 实时在轨对象目录
- 地球与太阳观测视图
- 桌面端、平板和移动端适配

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 技术栈

React · TypeScript · Three.js · React Three Fiber · Vite
