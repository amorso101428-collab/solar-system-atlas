Modifications by this project: dark-background removal into a white/alpha cloud
mask; 2048, 4096, 8192-pixel-wide pyramid; 512-pixel geographic patches with
2-pixel wrap gutters; WebP encoding. The finest pyramid preserves the source's
native 8192×4096 sampling; no enlarged low-resolution source is advertised as
new satellite detail. This is a saved global composite, not live cloud imagery.

See manifest.json for source SHA-256 and scripts/build-cloud-tiles.py for the
reproducible preparation pipeline. The cloud display height is 45 km for visual
navigation; it does not represent the measured altitude of each cloud.
